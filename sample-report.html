HIGH

No swap space is configured

Memory & swap · confidence: measured · memory.no_swap

With 3753 MB of RAM and no swap at all, exhausting memory leaves the kernel no option but to invoke the out-of-memory killer, which terminates applications instantly.

Likely root cause: No swap device exists. Swap is not only for emergencies: it also lets the kernel evict rarely-used anonymous pages, which frees RAM for the page cache and makes the desktop more responsive.

What you notice: Applications disappear without warning under load; the desktop has no safety margin; hibernation is impossible.

What to do:

  • Create a compressed zram swap device (fast, reversible, no repartitioning).
  • Alternatively create a swapfile, but on a mechanical disk it will be slow.

HIGH

Desktop search indexer is running on a mechanical disk (tracker-miner-fs-3, tracker-extract-3)

Services & startup · confidence: measured · services.indexer_running

A file indexer is actively walking the disk. On a 1 TB mechanical drive this generates a constant stream of small random reads that compete with everything else - it is the classic reason an otherwise healthy laptop feels permanently sluggish.

Likely root cause: tracker-miner-fs (Mint/Ubuntu) starts automatically per user and re-indexes on every change. Random I/O on a 5400 rpm disk is ~100 operations per second, so the queue never drains.

What you notice: High iowait, slow application launches, the disk LED flickering constantly, and fans spinning up while 'nothing is running'.

What to do:

  • Disable the indexer. Nothing on an Xfce desktop depends on it (Thunar's search works without it), and it can be re-enabled at any time.
  • If you want it, at least let it finish once: the first full index is the expensive part.

Automatic repair available: services.disable_indexers
